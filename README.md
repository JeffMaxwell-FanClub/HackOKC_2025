CampusFix replaces outdated, inconsistent, and manual reporting processes. It offers a centralized communication hub that improves visibility and supports efficient task management for students, faculty, staff, and maintenance teams.

## Overview

Our campus struggles with slow methods for reporting problems such as broken equipment, facility issues, or safety hazards. Students don’t always know where to report issues, and maintenance teams may have difficulty tracking and prioritizing incoming work.

This system simplifies the entire workflow—from submitting a maintenance request to resolving it.

## Key Features

- **Request Submission** – Users can easily submit maintenance requests with details, location information via interactive map, and file attachments.
- **Triage & Prioritization** – Maintenance teams can categorize, prioritize, and assign requests as they come in.
- **Administrative Dashboard** – Tools for maintenance teams to monitor workloads and ensure timely responses.

## Installation

### Prerequisites
- **Node.js**
- **NPM**
- **SQL Database**

### Quick Start

You can install and run the local development server using the following commands:

```bash
# Clone the repository
git clone [https://github.com/JeffMaxwell-FanClub/HackOKC_2025.git](https://github.com/JeffMaxwell-FanClub/HackOKC_2025.git)

# Navigate into the server directory
cd HackOKC_2025
cd server

# Install dependencies
npm i

# NOTICE: MUST MODIFY DATABASE VARIABLES

# Run database migrations and start server
npm start

# Open your browser
# Navigate to http://localhost:3000
```
