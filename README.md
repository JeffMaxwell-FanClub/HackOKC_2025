# Campus Maintenance Request & Work Item Management System

This project provides a platform for submitting, tracking, and managing maintenance issues across a campus environment. It is designed to replace outdated, inconsistent, or manual reporting processes and offer a streamlined experience for students, faculty, staff, and maintenance teams.

---

## Overview

Our campus struggles with slow methods for reporting problems such as broken equipment, facility issues, or safety hazards. Students don’t always know where to report issues, and maintenance teams may have difficulty tracking and prioritizing incoming work.

This system simplifies the entire workflow—from submitting a maintenance request to resolving it—by centralizing communication, improving visibility, and supporting efficient task management.

---

## Core Features

- **Request Submission** – Users can easily submit maintenance requests with details, location information with selection from a map, and file attachments.
- **Triage & Prioritization** – Maintenance teams can categorize, prioritize, and assign requests as they come in.
- **Administrative Dashboard** – Tools for maintenance teams to monitor workloads and ensure timely responses.

---

## Technology Stack

- **Frontend:** Tailwind CSS
- **Backend:** Node.js / Express
- **Database:** Microsoft SQL Server
- **Cloud:** Hosted in Microsoft Azure

---

## Installation

### Prerequisites

- Node.js 
- NPM

### Setup Steps

```bash
# Clone the repository
git clone https://github.com/JeffMaxwell-FanClub/HackOKC_2025.git

# Navigate into the server directory
cd HackOKC_2025
cd server
  
# Install packages
npm i

# Run database migrations (if applicable)
npm start

# Navigate to localhost:3000 to use the app!
```
